# PlayScout

Discover indie browser games, hidden gems, and free games worth playing.

## Stack
- React + Vite
- Supabase Auth + Postgres + Row Level Security
- Responsive dark UI
- GitHub Actions deployment to GitHub Pages

## Quick start
```bash
npm install
cp .env.example .env.local
npm run dev
```

See [SETUP.md](./SETUP.md) for Supabase setup, admin access, deployment, SEO, and AdSense readiness.

## Important
The repository contains no bundled third-party games. Add only games and assets you are authorized to list, embed, or promote. Never expose a Supabase service-role key in frontend code.
